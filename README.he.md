# מנהל הבוט (Discord Bot Manager)

אפליקציית שולחן עבודה ל-Windows לניהול בוט דיסקורד, בהשראת MEE6.

> [!WARNING]
> **השתמשו תמיד בגרסה האחרונה.** כל גרסה מתקנת באגים ומוסיפה בדיקות בטיחות, ולכן התוכנה עובדת טוב ובטוח יותר בגרסאות החדשות.
> חזרה לגרסה ישנה, או ניסיון של הגרסאות הראשונות, יכולים לסכן את השרת שלכם: יש בהן באגים שתוקנו מאוחר יותר, והבוט עלול להתנהג בשרת בצורה לא צפויה. לדוגמה:
> - בגרסאות 1.0.0 עד 1.0.2 העדכון מתוך האפליקציה לא מצליח להוריד גרסאות חדשות (צריך להוריד את האחרונה ידנית).
> - לפני 1.0.2 תזכורות אישיות יכלו לקרוס, ובעיית ה-Intents החסרים תוקנה רק ידנית.
>
> אם בכל זאת חוזרים לגרסה ישנה, זה על אחריותכם, וכדאי לעדכן שוב בהקדם.

## התקנה ראשונה (פעם אחת)

1. ודאו ש-Python מותקן (3.13 או 3.14). בודקים כך:
   ```powershell
   py --version
   ```
2. לחיצה כפולה על **`setup.cmd`**. הקובץ יוצר תיקיית `.venv` ומתקין את החבילות.

## הפעלה

- **`start.cmd`**: פותח את חלון האפליקציה. אם שירות הבוט לא רץ, הוא מופעל אוטומטית.
- **`start-service-only.cmd`**: מריץ רק את שירות הבוט, בלי חלון, עם לוגים בחלון שחור. עוצרים עם `Ctrl+C`.

קבצי ‎`.cmd`‎ לא נחסמים על ידי מדיניות הסקריפטים של PowerShell, ולכן מומלץ להשתמש בהם.

### הפעלה מתוך PowerShell

מתוך תיקיית הפרויקט:
```powershell
.\.venv\Scripts\python.exe app.py
```
הפקודה הזו לא דורשת `Activate.ps1`, ולכן עובדת גם כש-PowerShell חוסם סקריפטים.

### אם PowerShell חוסם סקריפטים

אם מופיעה השגיאה ‎`running scripts is disabled on this system`‎ (למשל כשמריצים `.venv\Scripts\Activate.ps1`), יש שתי אפשרויות:

- **לא להפעיל סקריפטים בכלל:** להשתמש ב-`start.cmd`, או להריץ את `python.exe` מתוך `.venv` כמו בפקודה למעלה.
- **לאפשר סקריפטים מקומיים, רק למשתמש שלך:**
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  ```
  לאשר עם `Y`. ההגדרה הזו לא דורשת הרשאות מנהל.
- **לאפשר רק לחלון הנוכחי:**
  ```powershell
  Set-ExecutionPolicy -Scope Process Bypass
  ```

## צעדים ראשונים

1. בעמוד **חיבור והגדרות** מדביקים את ה-Bot Token ולוחצים **שמור**, ואז **בדוק חיבור**.
2. אופציונלי: Anthropic API Key ו-User ID מורשה.
3. בעמוד **הרשאות והזמנה**:
   - לוחצים **צור קישור** ופותחים את הקישור.
   - בדיסקורד בוחרים שרת ולוחצים **Authorize**. האפליקציה לא מאשרת בשבילך.
4. לוחצים **הפעל בוט** בפינה העליונה. השרתים יופיעו ברשימת השרתים.
5. בעמוד **פרופיל הבוט** משנים שם ותמונה.

## מבנה האפליקציה (בהשראת MEE6)

- **תפריט צד:** כללי (לוח בקרה, חיבור והגדרות, פרופיל הבוט, הרשאות והזמנה), ואחריו הקטגוריות: **חיוני**, **ניהול שרת**, **כלים**, **התראות רשתות**, **משחקים וכיף**, **בינה מלאכותית**.
- **כרטיס לכל מודול:** שם, תיאור, מצב (פעיל, כבוי או בקרוב) ומתג. לחיצה על הכרטיס פותחת את הדף של המודול.
- **דף מודול:** מתג בראש הדף, הפקודות וההרשאות שהמודול צריך, וההגדרות שלו.
  - כשמשנים משהו, מופיע בתחתית פס **"זוהו שינויים! שמור / ביטול"**.
  - יציאה מהדף או החלפת שרת בלי שמירה מבקשת אישור.
- **בורר שרתים:** לכל שרת פרופיל נפרד. האפשרות **"הוסף שרת חדש"** פותחת את בונה קישור ההזמנה.
- **חיפוש מהיר:** `Ctrl+K` מחפש מודולים, הגדרות ופקודות.

**אזהרה באוטומוד:** הפעולה "אזהרה" רושמת אזהרה רק אם מודול האזהרות פעיל באותו שרת. אחרת היא רק מציגה הודעה בערוץ.

**מודולים נוספים (גרסה 1.0.2):**
- **Starboard:** הודעה שמקבלת מספיק ⭐ מועתקת לערוץ ייעודי.
- **מעקב הזמנות:** מי הזמין כל חבר חדש, ‎`/invites` ו-‎`/invites-top`.
- **כרטיסי תמיכה:** כפתור שפותח שרשור פרטי עם תפקידי הצוות (‎`/ticket-panel`, ‎`/ticket-close`).
- **תיבת הצעות:** ‎`/suggest` או כל הודעה בערוץ ההצעות הופכת לכרטיס עם 👍/👎 ושרשור דיון, ו-‎`/suggestion` משנה סטטוס.
- **סקרים:** ‎`/poll` עם הסקרים של דיסקורד עצמו.
- **הודעות Embed:** מעצבים באפליקציה ולוחצים "שלח לדיסקורד".
- **תזכורות:** הודעות חוזרות כל X דקות, ו-‎`/remind 10m ...` לתזכורת אישית.
- **ערוצי סטטיסטיקה:** ערוצי קול נעולים שהשם שלהם מראה מספר חברים, בוטים, בוסטים ועוד.
- **ערוצים זמניים:** נכנסים לערוץ "הצטרף כדי ליצור" ומקבלים ערוץ קול משלכם, שנמחק כשכולם יוצאים.
- **AFK:** ‎`/afk סיבה`. מי שמתייג אותך מקבל תשובה אוטומטית.
- **התראות רשתות:** YouTube, Twitch (צריך Client ID ו-Secret חינמיים), Reddit ו-RSS. ל-TikTok ול-X אין API חינמי, ולכן הם לא נתמכים.
- **הגרלות:** ‎`/giveaway start` עם כפתור השתתפות, זוכים אקראיים, ‎`end`, ‎`reroll`, ‎`list`.
- **ימי הולדת:** ‎`/birthday set 24/12`, ברכה בערוץ ותפקיד ליום ההולדת. אפשר להוסיף גם מהאפליקציה.

**Claude ומודולים:** כשכותבים לבוט משהו כמו "יום ההולדת של ג'ון ב-24/12", הוא מציע להוסיף את זה לימי ההולדת, ושומר רק אחרי שלוחצים "אשר" או כותבים "כן". אותו דבר לתזכורות, הגרלות וסקרים (כשהמודול פעיל בשרת). הוא גם עונה על שאלות כמו "מי כתב הכי הרבה בשרת?", לפי ספירת ההודעות של הבוט מהרגע שהוא פעיל.

**חסר Intent:** בראש עמודי המודולים יש כפתור "הפעל אוטומטית". הוא מפעיל את Server Members ו-Message Content דרך ה-API של דיסקורד (עובד לבוטים בפחות מ-100 שרתים) ומחבר את הבוט מחדש.

**אישור לפעולות מסוכנות:**
- ‎`/kick`, ‎`/ban`, ‎`/timeout` ו-‎`/purge` תמיד מציגות קודם כפתורי **אשר / ביטול**.
- רק מי שהפעיל את הפקודה יכול ללחוץ עליהם, ותוקפם פג אחרי 30 שניות.
- הבוט בודק היררכיה: אי אפשר לפעול על עצמך, על בעל השרת, או על מי שהתפקיד שלו גבוה משלך או מזה של הבוט.
- ‎`/unwarn` ו-‎`/clearwarns` מבקשות אישור גם הן.
- באפליקציה, מחיקת אזהרה, הסרת הודעת תפקידים והסרת פרופיל שרת דורשות אישור.
- כשמגדירים הרחקה או חסימה אוטומטית, האפליקציה מבקשת אישור לפני השמירה, כי הפעולות האלה יתבצעו בלי אישור ידני בכל פעם.

### הפעלת Privileged Intents

1. נכנסים ל-[Developer Portal](https://discord.com/developers/applications), בוחרים את הבוט ועוברים ללשונית **Bot**.
2. מפעילים **Server Members Intent** ו-**Message Content Intent**, ולוחצים **Save Changes**.
3. באפליקציה לוחצים **כבה בוט** ואז **הפעל בוט**.

האפליקציה מזהה לבד אילו Intents מופעלים. מודול שחסר לו Intent מסומן בתג אדום "חסר Intent", ותג "חסרות הרשאות" מופיע כשלבוט אין בשרת את ההרשאות שהמודול צריך.

**תפקיד הבוט:** כדי לתת תפקידים או להשתיק, תפקיד הבוט צריך להיות **מעל** התפקידים האלה. מסדרים את זה בהגדרות השרת, תחת תפקידים, בגרירה.

## רמות (Levels)

**איך צוברים XP:**
- כל הודעה בשרת נותנת 15–25 XP, לכל היותר פעם בדקה לכל משתמש. כך ספאם לא משתלם.
- הסכום מוכפל ב**קצב XP** שבחרת, מ-x0.25 עד x3.
- כדי לעבור מרמה L לרמה L+1 צריך ‎5·L² + 50·L + 100 XP: ‏100 לרמה 1, ו-155 נוספים לרמה 2.

**הגדרות בדף המודול:**
- **הודעת עליית רמה:** בערוץ שבו נכתבה ההודעה, בערוץ קבוע, בהודעה פרטית, או בלי הודעה. משתנים: `{player}` `{player_name}` `{level}` `{server}`.
- **תפקידים כפרס:**
  - טבלה של רמה ותפקיד.
  - מצב **לצבור** שומר את כל התפקידים שהושגו. מצב **רק הגבוה ביותר** מחליף לתפקיד של הרמה העליונה.
  - אפשר להסיר תפקידים כשמשתמש מאבד XP.
- **תפקידים וערוצים בלי XP:** לכל רשימה בוחרים "לחסום רק את הרשימה" או "לתת XP רק לרשימה".
- **צבע כרטיס הדירוג.**

**פקודות:**
- ‎`/rank`: כרטיס עם רמה, דירוג, XP כולל, מספר הודעות ופס התקדמות.
- ‎`/levels`: לוח מובילים, עשרה בכל עמוד.
- ‎`/give-xp` ו-‎`/remove-xp`: למי שיש לו הרשאת "ניהול השרת".

**לוח מובילים באפליקציה:**
- בדף המודול מוצגים 50 המובילים, עם רמה, פס התקדמות, XP והודעות.
- הכפתור **אפס** מוחק את ה-XP של משתמש, אחרי אישור. איפוס מהאפליקציה לא מסיר תפקידי פרס שכבר ניתנו.

**מה צריך:**
- לא צריך Privileged Intent, כי הודעות נספרות גם בלי Message Content.
- תפקיד הבוט צריך להיות מעל תפקידי הפרס.

## כלכלה (Economy)

המטבעות וירטואליים בלבד, בתוך השרת. אין שום קשר לכסף אמיתי.

**הגדרות בדף המודול:**
- **מטבע:** שם ואייקון. אפשר אימוג'י רגיל או אימוג'י של השרת.
- **יתרת פתיחה:** כמה מטבעות מקבל כל ארנק חדש.
- **‎`/daily`:** פרס בסיסי, ועוד תוספת לכל יום ברצף, עד מקסימום ימים שקובעים. הרצף נשמר אם לוקחים את הפרס בתוך 48 שעות מהפעם הקודמת.
- **משחקים:** מתג לכל משחק, והימור מינימלי ומקסימלי.
  - ‎`/dice`: שתי קוביות נגד הבוט, הסכום הגבוה מנצח.
  - ‎`/guess`: ניחוש מספר בין 1 ל-10. ניחוש נכון מחזיר פי 8.
  - ‎`/roulette`: אדום או שחור מחזירים פי 2, ירוק או מספר מדויק מחזירים פי 36.
  - ‎`/rps`: אבן, נייר ומספריים.
- **חנות:** לכל פריט שם, מחיר, תיאור, תפקיד שהוא נותן, תגובה אחרי קנייה, מלאי ומקסימום למשתמש.
- **Boosts:** בונוס באחוזים לפרס היומי ולזכיות, או הקטנה של הפסדים.
  - אפשר להגביל Boost לתפקיד מסוים. בלי תפקיד, הוא חל על כולם.
  - אפשר לקבוע תאריך סיום. בלי תאריך, ה-Boost קבוע.

**פקודות נוספות:**
- ‎`/balance` היתרה, ‎`/pay` העברה לחבר, ‎`/rich` העשירים בשרת.
- ‎`/shop` החנות, ‎`/buy` קנייה (עם השלמה אוטומטית של שמות הפריטים), ‎`/inventory` הפריטים שקנית.
- ‎`/give-coins` ו-‎`/remove-coins`: למי שיש לו הרשאת "ניהול השרת".

**באפליקציה:** טבלת העשירים בשרת, עם יתרה, רצף ופריטים. הכפתור **אפס** מוחק את הארנק של משתמש, אחרי אישור.

## אוטומציות ("כשקורה X, עשה Y")

עד 50 אוטומציות בכל שרת. לכל אחת יש מתג, שם, אירוע, תנאים, עד 5 פעולות שרצות לפי הסדר, וזמן המתנה בין הפעלות לאותו משתמש.

**אירועים:**
- נשלחה הודעה: כל הודעה, מכילה, מתחילה ב-, בדיוק, או מכילה את המילה. אפשר להגביל לערוץ.
- נוסף ריאקשן.
- חבר קיבל תפקיד, או הוסר לו תפקיד.
- חבר הצטרף לשרת.

**תנאים:** רק למי שיש לו תפקיד מסוים, ואפשרות להתעלם מבוטים (פעילה כברירת מחדל).

**פעולות:**
- שליחת הודעה: באותו ערוץ, בערוץ מסוים, או בהודעה פרטית.
- תגובה להודעה.
- מתן תפקיד, או הסרת תפקיד.
- הוספת ריאקשן.
- מחיקת ההודעה.
- פתיחת שרשור.

משתנים לטקסט: `{user}` `{username}` `{server}` `{channel}` `{message}` `{role}`.

**תבניות מוכנות:** ברוכים הבאים, שרשור לכל הודעה, אימות במילה, ריאקשן אוטומטי, הכרזה על תפקיד. אפשר גם לשכפל אוטומציה קיימת.

**בטיחות:**
- מחיקת אוטומציה מבקשת אישור.
- שמירה של אוטומציה שמוחקת הודעות מבקשת אישור.
- הבוט מתעלם מההודעות של עצמו, כדי שאוטומציות לא ייכנסו ללולאה.

## צ'אט עם Claude (שלב 4)

**הפעלה:**
1. בעמוד **חיבור והגדרות** שומרים Anthropic API Key, ולוחצים **בדוק חיבור**.
2. באותו עמוד ממלאים **User ID מורשה**. בלי User ID מורשה, הבוט לא עונה לאף אחד.
3. בעמוד **צ'אט עם Claude** מפעילים את המתג בשרת הרצוי.

**מתי הבוט עונה:**
- רק למשתמש המורשה. הודעות של כל אחד אחר נשמטות בשקט.
- בהודעה פרטית לבוט.
- בשרת, כשמתייגים את הבוט או עונים להודעה שלו.
- אם הוגדר **ערוץ מורשה**, הבוט עונה בשרת רק בו. אפשר להפעיל שם גם "לענות לכל הודעה", וזה דורש Message Content Intent.

**הגדרות לכל שרת:**
- הנחיות ל-Claude (System prompt)
- רמת מאמץ (ברירת מחדל: נמוכה, מהיר וזול)
- כמה הודעות קודמות לזכור
- המתנה בין הודעות
- מגבלת תשובות ליום

**פרטים נוספים:**
- המודל הוא `claude-haiku-5-5`.
- הזיכרון נשמר בזיכרון בלבד, בנפרד לכל ערוץ. הוא נמחק כשהבוט נכבה, או עם הפקודה ‎`/claude_reset`.
- תוכן ההודעות לא נכתב ללוג. נרשם רק מספר הטוקנים.
- בעמוד יש מונה תשובות ועלות משוערת. החיוב האמיתי מופיע ב-[Anthropic Console](https://console.anthropic.com).
- ל-Claude אין גישה לפעולות ניהול. הוא רק משוחח.

## ארכיטקטורה

- `botd/`: שירות הבוט, בלי קוד ממשק.
  - `bot.py`: discord.py (הפעלה, כיבוי, שרתים).
  - `api.py`: API מקומי ל-`127.0.0.1` בלבד, עם טוקן גישה חדש בכל הפעלה.
  - `store.py`: הגדרות ופרופיל לכל שרת (SQLite).
  - `secrets_store.py`: keyring.
  - `redact.py`: הסתרת סודות מהלוגים.
  - `catalog.py`: הרשאות, מודולים והגדרות לכל מודול.
  - `modules/`: מודול (Cog) לכל יכולת.
- `ui/`: הממשק (HTML, CSS, JS, בלי שלב build).
- `app.py`: חלון שולחן העבודה (pywebview / Edge WebView2). כשסוגרים את החלון השירות נעצר, אלא אם הופעל "השאר רץ ברקע".
